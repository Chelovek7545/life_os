# Перетаскивание задач

Чтобы начать перенос, нажмите на карточку или строку задачи и удерживайте её.
Допустимая цель подсветится. В сетке времени появится контур будущего блока
с началом и окончанием.

На экране Tasks задачи можно брать из списков, канбана, календаря, иерархии
и панели **Unscheduled** («Без расписания»). В «Пространстве» можно переносить
задачи между видимыми областями, например из «Задач по проектам» в календарь.

| Куда перенести | Что произойдёт |
| --- | --- |
| День в недельном списке | Задача без расписания получает дату без времени. У запланированной задачи сдвигается весь период с сохранением времени. Если задача занимает несколько дней, перенос привязывается к дню, за карточку которого её взяли. |
| Панель дней над сеткой календаря | Задача получает дату без времени. Если задача уже запланирована без времени или занимает несколько дней, перенос сдвигает её расписание целиком. Скрытую панель можно вернуть кнопкой «Показать задачи без времени» в шапке календаря. |
| Сетка времени календаря | Задача получает показанные дату и время. Для задачи без расписания создаётся часовой блок. Многодневную задачу без времени можно перенести через панель дней. |
| **Unscheduled** | У задачи очищаются даты начала и окончания, дедлайн сохраняется. Панель открывается кнопкой с лотком и принимает запланированные задачи, даже когда список пуст. |
| Колонка канбана | Задача получает статус колонки. |
| Другая задача в иерархии | Вся ветка переносимой задачи перемещается под целевую. Подсвечиваются кандидаты, которых можно назначить новым родителем без образования цикла. |

## Реализация

Источники используют `TaskDraggable` из `lib/core/ui/task_drag.dart`.
Данные `TaskDrag` содержат задачу и при необходимости день исходной карточки
или ссылку на исходный таймлайн. Цель принимает `DragTarget<TaskDrag>` и
вызывает соответствующую команду по ID задачи.

Канбан использует `TaskCommands.setTaskStatus`. Иерархия использует
`TaskCommands.moveTaskUnder`. SQLite проверяет цепочку предков и записывает
связь с родителем в одной транзакции. При включённом журнале синхронизации
смена родителя создаёт ревизию переносимой задачи.
